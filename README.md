# Comp484-Project-1# RackIt

A static HTML/CSS website for COMP 484 Project 1. RackIt is a workout-tracking concept site with a home page, a sample 3-day routine, an exercise library, and a progress preview.

## Pages
- `index.html` - Home
- `workouts.html` - Workout routines
- `exercises.html` - Exercise library with search and form tips
- `progress.html` - Sample progress stats

## MDN Exploration
- **Elements:** `<datalist>`, `<data>`, `<wbr>`
- **Attributes:** `inputmode`, `popover`, `tabindex`

## Built With
HTML and CSS only. No frameworks.
